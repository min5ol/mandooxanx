## YouTube Downloader · 유튜브 다운로드 v1.1.0

> 더 적게 누르고, 더 많이 즐기기.

[🥟 최신 단축어 설치](https://www.icloud.com/shortcuts/219734a165a443178ef31e03231f791c) · [Notion 사용 안내](https://app.notion.com/p/41e672d9690b812a9658e32d6458de5a)

### 지원 기능

- **영상 및 Shorts** · 일반 영상과 Shorts를 MP4로 저장합니다. 영상과 썸네일 동시 저장, JPG 썸네일 단독 저장도 지원합니다.
- **음원 추출** · M4A(AAC) 또는 MP3로 추출하여 파일 앱에 저장합니다.
- **화질 선택** · 최고화질 또는 2160p·1440p·1080p·720p·480p 이하를 선택합니다. 실제 제공 화질은 영상에 따라 다릅니다.
- **날짜 선택** · 원본 게시일 또는 다운로드 날짜를 기록합니다. 게시일을 확인할 수 없는 경우 대체 날짜를 안내합니다.
- **링크 입력** · YouTube 공유 시트, 복사한 링크, 단축어 앱에서 직접 링크 입력을 지원합니다.
- **저장 위치** · 영상·썸네일은 사진 앱에 직접 저장하고 음원은 파일 앱에 저장합니다. 완료 알림에서 화질·용량·날짜 등 확인 가능한 정보를 표시합니다.
- **자동 업데이트 확인** · 새 작업 시작 전에 최신 버전을 확인합니다. 업데이트 안내에서 설치를 선택하거나 최신 공유 링크에서 직접 교체할 수 있습니다. 무인 자동 설치는 하지 않습니다.

### v1.1.0 업데이트 (2026.11.27)

- **항상 설정** · 항상 최고화질, 항상 원본 게시 날짜, 항상 다운로드 날짜, 항상 호환 변환 허용을 선택하면 다음 실행부터 해당 메뉴를 생략합니다. 단축어 앱에서 직접 실행해 ‘항상 설정 초기화’를 선택하면 다시 선택할 수 있습니다.
- **영상으로 돌아가기** · YouTube 공유 시트에서 실행한 경우 저장 완료 알림의 확인 버튼을 누르면 해당 영상 또는 Shorts 링크를 다시 엽니다. 직접 입력·클립보드 실행에서는 강제 복귀하지 않습니다. 기존 재생 위치 복원은 보장하지 않습니다.
- **대용량 영상 저장** · 사진 앱 직접 저장 방식을 도입하여 대용량 파일 전달 과정의 부담을 줄였습니다. 제작자 기기에서 30분 이상 및 1GB 이상 영상 저장을 확인했습니다.
- **원본 품질 보존** · 호환 가능한 H.264·HEVC와 오디오 스트림은 복사를 우선합니다. 호환 변환은 동의한 경우에만 진행하며, 해상도·FPS·코덱·용량 등 최종 파일 정보를 확인합니다. 호환 가능한 HDR 소스도 보존을 우선합니다.
- **다운로드 안정성** · 저장 공간 사전 검사, 조건부 중단 다운로드 이어받기와 완료 소스 재사용, 저장 상태 확인 및 작업별 복귀 스크립트를 추가했습니다. 서버 및 소스 조건에 따라 이어받기가 불가능할 수 있습니다.
- **새로운 실행 화면** · MANDOO STUDIO Console UI 1.0: 현재 작업 단계, 실측 진행률·용량·속도·남은 시간(확인 가능한 경우), 파일 검증 및 저장 상태를 표시합니다.
- **오류 안내** · 실패 단계별 오류 코드, 원인·해결 방법 및 제보 정보 복사 기능을 개선했습니다. 부분 성공과 전체 성공을 구분하고 저장 실패 파일을 보존하는 경로를 마련했습니다.

### 설치 및 사용 방법

iPhone에 a-Shell mini를 설치한 뒤 iCloud 링크에서 단축어를 추가하세요. 기존 버전은 교체하고 이름은 ‘유튜브 다운로드’를 유지해 주세요. 처음 실행 시 필요한 권한(사진 추가 등)을 허용하고 구성요소 준비가 끝날 때까지 a-Shell mini를 강제 종료하지 마세요.

YouTube 영상의 공유 메뉴에서 유튜브 다운로드를 선택하거나, 단축어 앱에서 직접 실행하여 복사한 링크 또는 직접 입력을 선택하세요. 저장 종류·화질·날짜·필요시 호환 변환 여부를 선택한 뒤 작업 완료를 기다리세요. 사진 앱의 최근 저장된 항목 또는 게시일, 음원은 선택한 파일 앱 위치에서 확인하세요.

제작자 기기에서 주요 기능을 확인했습니다. 이어받기·재사용·저장 공간 부족·신규 설치 및 업데이트 알림 등 일부 예외 경로는 추가 실기기 확인이 필요하며, 네트워크·YouTube 정책·iOS 환경에 따라 결과가 다를 수 있습니다.

## 구성

| 파일 | 역할 |
| --- | --- |
| `docs/updates.json` | 단축어별 최신 공개 버전, 실제 설치 링크, 변경 내역 |
| `docs/index.html` | GitHub Pages 방문자를 Notion 배포 허브로 안내 |
| `scripts/validate_manifest.py` | JSON 형식, 버전 코드, iCloud URL을 배포 전 검사 |
| `.github/workflows/publish-pages.yml` | PR에서 JSON 검사, main 병합 뒤 GitHub Pages 자동 배포 |

> **현재 공개 버전:** YouTube Downloader **v1.1.0**, 인스타 미디어 다운로드 **v1.0.1**. 두 항목 모두 `published`로 등록되어 있습니다. 설치 환경은 iPhone + a-Shell mini이며, 기기별 최초 실행 검증은 별도로 권장합니다.

## 처음 설정할 때

GitHub Pages 배포는 Actions 워크플로를 사용합니다. `main`에 병합되면 검증 후 자동 배포를 시도합니다.

배포가 활성화되지 않았다면 [Settings → Pages](https://github.com/min5ol/mandooxanx/settings/pages)에서 **Build and deployment → Source: GitHub Actions**를 선택한 다음 Actions의 **Validate and publish MANDOO Update**를 다시 실행합니다. Pages 활성화 자체는 코드 검증과 별개입니다.

## 새 버전 배포하기

1. Apple 단축어에서 **새 버전의 실제 공유 링크**를 발급합니다.
2. `docs/updates.json`에서 해당 단축어의 `status`를 `published`로 바꿉니다.
3. `version`, `version_code`, `install_url`, `notes`를 최신 버전으로 수정합니다.
4. 브랜치를 만들어 PR을 열고, JSON 검증을 통과한 뒤 `main`에 병합합니다.
5. GitHub Pages의 JSON이 새 버전을 제공하는지 확인합니다.

버전 코드는 `major * 1,000,000 + minor * 1,000 + patch`를 사용합니다.

예시: `1.0.0` → `1000000`, `1.0.1` → `1000001`.

## 보안과 사용자 경험

- 검증된 `https://www.icloud.com/shortcuts/<32자리 ID>`만 공개합니다.
- 공개 JSON과 설치 링크는 외부에 보이는 값입니다. 개인 키, 토큰, 비밀번호를 절대 넣지 않습니다.
- **자동 확인**과 **무인 자동 설치**는 다릅니다. 설치·기존 단축어 교체에는 사용자의 승인이 필요합니다.
- YouTube Downloader와 인스타 미디어 다운로드는 **새 다운로드 실행 시 다운로드 작업 전에** 공개 버전을 확인하고, 새 버전이 있으면 설치할지 선택하도록 설계했습니다. 콜백 복귀에는 업데이트 확인을 중복 실행하지 않습니다.
- 설치된 단축어 내 버전 코드·업데이트 분기는 iPhone 실기기에서 별도로 확인해야 합니다.
- 내부 Python 엔진 버전과 사용자 공개 버전은 별도로 관리합니다.
